\chapter{Introduction}

This user guide provides a practical overview of how to use the \texttt{PrimePie} library. Rather than focusing on the underlying mathematical theory or algorithmic design, this document is dedicated to demonstrating how to work with the library from the user's perspective.

Through concise and focused examples, users will learn how to import and interact with the various components of the library, including core number theory utilities, algebraic structures, and cryptographic primitives (\textcolor{red}{in the future}). Each section includes annotated code snippets and explanations to help both beginners and advanced users integrate \texttt{PrimePie} into their own projects.

For the theoretical background and detailed explanation of the algorithms implemented, please refer to the accompanying document.
